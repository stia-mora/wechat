## 实际采集限制

公众号采集已达到验收数量。之后尝试机器之心、第一财经的文章列表时，微信返回 `ret=200013, msg=freq control`。随即停止文章采集，4 个追加同步任务保留为 `blocked`，未持续重试。

因此本次交付数据库的**真实文章数量为 0**。文章列表、正文清洗与阅读、摘要和画像功能已实现，但没有将其描述为已完成真实内容验证。源码内的隔离测试文章在事务结束后全部回滚，不进入快照或采集统计。

LLM 兼容接口、结构化校验、缓存与人工审核已实现。当前没有配置实际模型密钥与模型名，因此没有真实 AI 画像 / 摘要；页面如实展示待分析状态。配置后可通过后台运行任务。
