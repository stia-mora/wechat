浏览器上报主要覆盖启用 JavaScript 的访问，包括站内切换页面；已识别的机器人和自动化浏览器不发送上报。浏览器特征不能证明访客一定是真人。访客数按每天的匿名网络地址与浏览器特征估算，多日显示日访客数合计，不是跨日独立人数。

HTTP 请求统计来自源站日志，包含不执行 JavaScript 的爬虫。预加载、静态资源、API 和后台请求不计入。AI 分类依据 User-Agent 声明；伪装成普通浏览器的 Agent 可能无法识别。AI 平台引荐表示用户从该平台点击了链接，与 AI 抓取分开统计。

来源依据引荐域名，浏览器或平台不传递来源时归入直接 / 未知。不保存搜索词、完整引荐网址或页面查询参数。Cloudflare 缓存命中、被边缘拦截的请求可能不进入源站日志；浏览器上报也会受到脚本拦截或 Do Not Track 设置影响。

每天按北京时间划分，每分钟更新报表，日志保留 30 天。监控从本次上线开始积累数据，不补造历史访问。
